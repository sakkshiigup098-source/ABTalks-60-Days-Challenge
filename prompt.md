# AI Usage Log — ABTalks 60-Day Coding Challenge

## Project
ABTalks — 60 Day Coding Challenge

## AI Tools Used
- ChatGPT
- Cursor AI

## How AI Was Used

### 1. Project Planning
AI was used to plan the structure and features of the ABTalks platform, including:
- Landing page
- Dashboard
- 60-day challenge tracking
- AI Coach
- Ranking
- Profile
- History
- Challenge Day pages

### 2. UI Development
AI was used to help create and refine React components and CSS/SCSS styling.

### 3. Routing
AI helped configure React Router routes for:
- `/`
- `/dashboard`
- `/day/12`

### 4. Debugging
AI was used to troubleshoot GitHub, Git, and Vercel deployment issues, including routing and deployment errors.

### 5. Documentation
AI helped structure the README and project documentation.

## Human Contribution

The project structure, implementation decisions, testing, integration, and final submission were reviewed and completed by the project developer.

## AI Development Philosophy

AI was used as a development assistant for brainstorming, debugging, code suggestions, and documentation. The final project was reviewed, modified, tested, and integrated by the developer.
